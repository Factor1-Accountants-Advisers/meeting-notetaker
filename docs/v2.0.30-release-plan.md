**3.2 — Comms correction for DA's announcement.** His draft says
*"Automatic start only works if you join … no earlier than 3 minutes
before the start time, any earlier and you must start manually."* That is
not the behaviour: joining early is fine — the recording simply starts at
−3 (the watcher reads the call history when it arms; harness s1, plan row

(b) hybrid / in-room without clicking Join → the +2 prompt, one click on
**Record now**; (c) phone-join records the desktop (F1) until the device
check ships; (d) a join after the scheduled end is not recorded.
